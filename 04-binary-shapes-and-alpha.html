第 4 课：解码 Predy JSON 里的真实二进制 bins[0].b64 (72 个三角形扇形拼出 idea-dot)

💡 揭秘 Predy JSON 的 shapes[0]：
"v": [20, [0, 0, 592, "f32"]] 表示从第 0 字节开始取 592 字节作为 Float32Array（共 74 个 2D 顶点，第 0 个点是圆心 (0,0)，其余是圆周上的点）；
"i": [20, [0, 592, 432, "u16"]] 表示从第 592 字节开始取 432 字节作为 Uint16Array 索引（0,1,2, 0,2,3... 共 216 个索引 = 72 个三角形）！
